# FlyAI frontend

React/Vite interface for flight search and alert configuration.

See the [repository README](../README.md) for installation, backend configuration and validation limits. From this directory, use `npm ci`, `npm run dev`, `npm run lint` and `npm run build`. Set `VITE_API_URL` to your test backend origin when it differs from `http://localhost:5000`.

A successful frontend build does not validate backend authentication, alert privacy, external flight data or email delivery. Use synthetic data until the controls described in the main README have been addressed.
